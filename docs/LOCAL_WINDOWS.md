# Запуск Tendr на вашем Windows-компьютере

`localhost` — компьютер, на котором открыт браузер. Запуск в облачной среде Codex не запускает приложение на вашем ноутбуке. Инструмент публичного preview/туннеля в текущей среде отсутствует.

## Полный запуск

Установите Git, Node.js LTS (22.12 или новее) и Docker Desktop. Запустите Docker Desktop, дождитесь готовности движка, затем откройте PowerShell **в папке проекта tendr**:

```powershell
git fetch origin
git switch fix/audit-hardening-2026-10-13
git pull --ff-only
powershell -ExecutionPolicy Bypass -File .\scripts\start_local.ps1
```

При ошибке переключения ветки из-за ваших незакоммиченных изменений сохраните их перед переключением; не используйте reset --hard. Если репозиторий ещё не скачан:

```powershell
git clone --branch fix/audit-hardening-2026-10-13 https://github.com/amirlan-io/tendr.git
cd tendr
powershell -ExecutionPolicy Bypass -File .\scripts\start_local.ps1
```

Если движок Docker не запущен, скрипт открывает Docker Desktop и ждёт готовности. При первом запуске подтвердите запросы в окне Docker Desktop. Если там показана ошибка WSL/виртуализации, её нужно устранить до повторного запуска.

Скрипт устанавливает frontend, собирает и запускает API, PostgreSQL, Redis и Qdrant, применяет миграции и проверяет готовность. Frontend открывается в отдельном окне терминала; оставьте его открытым. Скрипт выбирает свободные порты, начиная с 8000 для API и 5173 для сайта, и открывает выбранный адрес в браузере только после ответа обоих серверов. Например, если 5173 занят, сайт откроется на 5174. Адреса печатаются в терминале. Для приватного репозитория GitHub попросит обычную авторизацию; не присылайте токен в чат.

Существующий `.env` читается, если есть; скрипт его не создаёт и не перезаписывает. Для просмотра главной и тарифов ключи внешних сервисов не нужны. Авторизация, реальные AI-запросы и оплата требуют своих настроенных ключей. В локальном Compose инфраструктура имеет отдельные тома; наружу опубликован только API на loopback. Указанный пароль БД — исключительно локальная настройка разработки, не production-секрет.

Остановка backend без удаления данных:

```powershell
docker compose -f infra/docker-compose.local.yml down
```

Frontend остановите Ctrl+C в отдельном окне. Занятые порты обходятся автоматически. Чужие программы не останавливаются; Vite proxy и CORS API используют выбранные порты. Не применяйте этот dev Compose для боевого сервера.

## Только посмотреть тарифную страницу

Если Docker Desktop пока не установлен, после скачивания нужной ветки можно запустить одну главную страницу:

```powershell
cd web
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

После строки `Local: http://127.0.0.1:5173/` откройте http://localhost:5173/#pricing. Backend и приватные функции в этом режиме не запущены.

## Проверки в облачной среде

Локальный Compose проверен на Linux с отдельным project name и тестовым портом: чистые миграции до d02a13c004, PostgreSQL/Redis/Qdrant/API healthy, live API=200 и новые тарифы подтверждены. Образ проверен через доверенный offline wheelhouse из-за DNS прокси при обычном Docker build. Тестовые контейнеры и тома удалены после проверки. Запуск самого `.ps1` на Windows здесь недоступен. Поэтому работоспособность PowerShell-скрипта на вашем конкретном Windows-компьютере до вашего запуска не подтверждена.
