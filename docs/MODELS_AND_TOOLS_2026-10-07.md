Сравнение скорости и найденных карточек поэтому ориентировочное. На этих прогонах Gemini сократил время примерно вдвое, но не решил проблему источников. Между прогонами менялись поисковая выдача и часть локальных правил оценки: количество заказа было исключено из характеристик товара. Поэтому рост числа карточек фильтра нельзя приписать только модели. В каталоге AnyModel коэффициент Gemini — 0,6 за токен против 0,25 у Qwen Max, поэтому меньшая задержка сама по себе не означает меньший расход баланса.

## Инструменты, которые имеют смысл для проекта

1. **AnyModel rerank**: каталог `/v1/models/rerank` вернул `am/llama-nemotron-rerank-vl-1b-v2` с нулевым коэффициентом; `/v1/rerank` ответил 200. На трёх простых карточках правильный стол занял место 1, похожий неподходящий — место 2, диван — место 3. Последующая проверка на двух реальных поисковых выдачах показала ограничение: стол с неподходящей ценой остался первым, чугунный регулятор вместо стального тоже остался первым. Сам по себе rerank **не годится как фильтр соответствия ТЗ**. [Живой тест](anymodel-rerank-live-2026-10-07.json), [документация AnyModel](https://anymodel.org/api-docs.md).
2. **Firecrawl API**: официальный инструмент умеет получать страницу товара как markdown или структурированный JSON и читать каталоги. Пробовать как резервный способ для страниц, на которых прямой HTML, Jina и Tavily не дали полных характеристик. Потребуется отдельный доступ/API-ключ и измерение качества на конкретных казахстанских магазинах до интеграции. Подсказка о плагине Firecrawl для ручных проверок предложена в чате; подключение плагина само по себе не подключает сервис к backend. [Документация Firecrawl](https://docs.firecrawl.dev/developer-guides/common-sites/amazon).
3. **Официальный OWS goszakup**: система уже умеет использовать этот API для лотов; в текущей локальной конфигурации токен задан, URL указывает на v2. API даёт первичные поля, включая описание, количество и сумму. Проверить полноту полей и необходимость v3 на реальном лоте: это ценнее пересказа страницы для условий закупки. [Официальная документация OWS v3](https://old.goszakup.gov.kz/ru/developer/ows_v3).

У проекта уже есть Tavily Search/Extract, Jina Reader, Browser-Use, OCR PDF и парсеры документов. Дополнительный сервис чтения страниц имеет смысл только после сравнения с ними на одном наборе недоступных карточек. Главный текущий пробел — качество и полнота источников: в результатах поиска часто оказываются страницы категорий и объявления без точных размеров, гарантии или условий доставки.

Пока разумно использовать Gemini Flash как быстрый кандидат для пилотного режима и продолжить проверку на реальных лотах. Смена модели сама по себе не даёт полного набора проверенных поставщиков. Ключ тестового AnyModel хранится только во временном файле вне проекта. Производственная конфигурация не менялась. Коммитов и операций с GitHub нет.
