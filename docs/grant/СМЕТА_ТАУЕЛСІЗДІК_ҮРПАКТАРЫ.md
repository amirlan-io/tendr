## Детальное обоснование ключевых статей (для жюри)

### Статья 1.4 (Mistral API, 420К) — основной LLM для агентов

**Почему именно Mistral:**
- Поддерживает казахский и русский языки
- OpenAI-совместимый API
- Используется для Documenter Agent, Legal Agent, B2G Agent, ProductSearch Agent
- На момент запуска (текущая стадия) используется free-тариф, но с ростом пользователей расходы вырастут
- Альтернатива — проприетарный Claude или GPT-4, но они дороже в 3-5 раз

**Почему не open-source полностью:**
- open-source модели (LLaMA, Mistral-7B) требуют мощного GPU-сервера (от 200К тг/мес на AWS)
- На текущей стадии (50-100 пользователей) облачный API оптимальнее
- План: при 1000+ пользователей переход на собственный GPU-сервер

**План масштабирования (что в отчёте):**
- 0-50 пользователей: free-тариф (0 ₸/мес)
- 50-200 пользователей: Mistral pay-as-you-go (~35К ₸/мес)
- 200+ пользователей: Mistral Team план + alemLLM резерв

### Статья 1.8 (VPS, 25К) — production-окружение

**Почему VPS:**
- Продукт работает 24/7 — нужен сервер
- На своём ПК нельзя (отключения, сбои питания)
- VPS в Алматы (ps.kz, hoster.kz) — низкий пинг для казахстанских пользователей
- Конфигурация: 2 vCPU, 4 GB RAM, 40 GB SSD — достаточно для FastAPI + PostgreSQL + Qdrant + Nginx
- Альтернатива: serverless (Vercel, Railway) — но в KZ нужны локальные серверы для Telegram API

**Текущий статус:** используется локальный ПК грантополучателя (стадия разработки), но для пилота нужен VPS.

### Статья 2 (Маркетинг, 400К) — привлечение пользователей

**Почему Instagram (а не Google Ads):**
- Целевая аудитория Tendr (предприниматели 25-40 лет) — 70% в Instagram
- В Казахстане Instagram — основная соцсеть для бизнеса
- Стоимость привлечения 1 пользователя: ~150-300 ₸ (таргет), 0 ₸ (органика)
- ROI: при 20 привлеченных SMB × 9900 ₸/мес подписка = 198К/мес

**План маркетинга:**
- Месяц 1-2: создание контента, посты в Instagram/Telegram, 30К/мес
- Месяц 3-4: таргетинг на предпринимателей 25-40 в Алматы, 30К/мес
- Месяц 5+: ретаргетинг, партнёрства, 25К/мес
- При успехе: Telegram-каналы + отзывы пользователей

### Статья 7 (Призы пилотам, 200К) — стимул для обратной связи

**Почему важно:**
- По Правилам гранта нужны **отчёты** о результатах
- Без пилотных SMB нечего отчитываться
- 40К ₸ за отзыв — достаточный стимул для предпринимателя (≈1 час консультации у юриста)
- 5 пилотов × 40К = 200К — это **3-5%** от бюджета (нормально для стимулирования пилотной программы)

**Формат:**
- Договор на тестирование (1 стр.)
- 2 часа использования продукта + заполнение анкеты (10 вопросов)
- Выплата через Kaspi на личную карту
- Чек об оплате в отчётность

### Частые вопросы жюри по смете

**Q: Почему VPS в Алматы, а не дешевле в Москве?**
A: Пинг для казахстанских пользователей. Сервер в Москве = +200 мс задержки. Для Telegram-бота это критично.

**Q: Почему Mistral, а не Yandex GPT или Kaspi GPT?**
A: У нас казахстанский проект. Зарубежные API (Mistral) — независимы от вендора, поддерживают казахский. Yandex GPT не поддерживает kk в полной мере. Kaspi GPT (если есть) — нужно исследовать.

**Q: Почему смартфон 150К, а не дешевле?**
A: Для тестирования Telegram Mini App и адаптивного дизайна нужен актуальный смартфон. 150К — Redmi/A-серия Samsung, не флагман. После проекта остается грантополучателю как оборудование.

**Q: Зачем бонус пилотам?**
A: Без пилотных пользователей не будет метрик для отчёта. Стимулируем участие 5 SMB.
