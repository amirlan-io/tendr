# Ноутбук и инструменты поиска: проверка 7 октября 2026

По SSH проверен ноутбук `project@192.168.1.183`. Он работает под Linux Mint 22.3, имеет Intel i5-4200U (2 ядра/4 потока), 3,7 ГиБ RAM и достаточно свободного места. Доступ к обычным веб-страницам есть. Ключи API и код основного приложения на ноутбук не копировались; публичный сервис не запускался.

## Что показала проверка

| Источник / способ | Текущая машина | Ноутбук | Вывод |
|---|---|---|---|
| Прямой HTTP к карточке Arlan | HTTP 200, 1,20 с | HTTP 200, 1,32 с | Дополнительного сетевого преимущества нет |
| Прямой HTTP к карточке Kaspi | Тайм-аут 15 с | Тайм-аут 15 с | Второй IP в этой локальной сети не устранил ограничение |
| Браузер Playwright, Kaspi | HTTP 200, выбран город Астана, видна цена 2 692 ₸ | То же | Браузерное чтение действительно даёт данные, которых нет в прямом HTTP |

Локальный Playwright после выбора города открыл вкладку «Характеристики»: тип «топливный фильтр», Chevrolet Cobalt, OEM и артикул. По умолчанию страница показывала также рассрочку 898 ₸ × 3; это **не цена товара**. Цена 2 692 ₸ берётся из отдельного блока «Цена». На ноутбуке в контрольном скрипте подтверждены тот же статус, выбранный город и цена; вкладка характеристик дополнительно проверена на текущей машине.

[Локальный результат](playwright-kaspi-probe-2026-10-07.json), [результат ноутбука](playwright-kaspi-remote-2026-10-07.json), [скрипт](../scripts/probe_local_browser_page.py).

Для пилота создано постоянное Python-окружение `/home/project/tendr-browser-worker/venv` с Playwright, Chromium находится в кэше пользователя. Для создания окружения ранее был установлен системный пакет `python3.12-venv`; вместе с ним пакетный менеджер обновил пять пакетов Python 3.12. Рабочий скрипт — `/home/project/tendr-browser-worker/worker.py`, его исходник находится в [scripts/ssh_browser_worker.py](../scripts/ssh_browser_worker.py). Публичная служба и автозапуск не создавались: приложение запускает браузер через SSH по мере необходимости.

## Проверенные альтернативы

- Облачный Browser-Use проекта с моделью `gpt-5.4-mini` вернул 403: модель недоступна бесплатному плану. Старый идентификатор `browser-use-2.0` вернул 422. Допустимый `bu-mini` вернул 402: на счёте $0, для запуска требуется не менее $1. Выбор модели резервного чтения сменён на `bu-mini`; при ошибке тарифа агент прекращает повторять одинаковый неудачный вызов для остальных карточек. До пополнения счёта этот сервис всё ещё не сможет читать страницы. [Проверки](browser-source-probe-bu-mini-2026-10-07.json), [тарифы Browser-Use](https://browser-use.com/pricing).
- Бесплатный AnyModel rerank ответил, но на реальных выдачах оставил первым стол вне бюджета и чугунный регулятор вместо стального. Как самостоятельный фильтр соответствия ТЗ он непригоден. [Результат](anymodel-rerank-live-2026-10-07.json), [документация AnyModel](https://anymodel.org/api-docs.md).
- Плагин Firecrawl был предложен для ручного исследования сложных страниц, но не подключён и не проверен на данных проекта; ключа Firecrawl API для приложения нет.

## Решение по использованию ноутбука

Ноутбук **подключён к агенту как отдельный узел браузерного чтения** для карточек Kaspi. Backend обращается к нему только по SSH-ключу, хранит приватный ключ и проверенный host key вне репозитория; на ноутбук не копировались ключи LLM/Tavily и данные клиентов. Адреса ограничены HTTPS-карточками `kaspi.kz/shop/p/`, один браузерный вызов выполняется за раз, ожидание ограничено 45 секундами. Если ноутбук или карточка недоступны, агент переходит к обычному чтению страницы. В коде настройка выключена по умолчанию; на текущей машине она включена в локальном игнорируемом `.env` через `BROWSER_WORKER_SSH_TARGET`, `BROWSER_WORKER_SSH_KEY_FILE`, `BROWSER_WORKER_SSH_KNOWN_HOSTS`. Исходник интеграции — [ssh_browser.py](../backend/app/agents/ssh_browser.py).

На одной известной карточке фильтра (`Chevrolet Cobalt`, OEM 13592336) агент с той же моделью Gemini подтвердил характеристики и цену 2 692 ₸ в обоих режимах. С ноутбуком он дополнительно установил город цены Астана и сохранил источник `ssh_browser`; время одного прогона снизилось с 20,8 до 11,5 секунды. Расчёт 10 штук — 26 920 ₸, без доставки. [Без ноутбука](kaspi-agent-without-laptop-2026-10-07.json), [с ноутбуком](kaspi-agent-with-laptop-2026-10-07.json).

Первый широкий прогон песочницы с ноутбуком не улучшил итоговую подборку: найденные карточки Kaspi не вошли в первые пять читаемых страниц. После этого агенту добавлена проверка нескольких конкретных карточек, оказавшихся ниже этой границы. Следующий широкий прогон дал ноль подтверждённых кандидатов, потому что поисковая выдача вообще не содержала Kaspi-карточек; это ограничение поиска и источников, которое ноутбук не исправляет. В первом точном поиске по артикулу карточка была найдена, но браузер её не принял из-за завершающего `/` в каноническом URL Kaspi. Проверка пути исправлена и закреплена тестом. [Широкий прогон без ноутбука](kaspi-agent-sandbox-without-laptop-2026-10-07.json), [первый с ноутбуком](kaspi-agent-sandbox-with-laptop-2026-10-07.json), [после расширения чтения](kaspi-agent-sandbox-improved-2026-10-07.json), [точный поиск до исправления URL](kaspi-exact-sandbox-with-laptop-2026-10-07.json).

После исправления повторный **точный поиск по артикулу** дал измеримое улучшение: одна карточка Kaspi получила `price_kzt=2692`, `city=Астана`, `estimated_total_kzt=26920`, `budget_status=within_budget`, статус `fits` и источник `ssh_browser`. В запуске без ноутбука та же карточка имела `price_kzt=null` и `budget_status=unknown`, хотя соответствие модели товара было подтверждено. Итоговые времена — 87,7 и 120,4 с; это разные живые поисковые выдачи, поэтому разницу во времени нельзя целиком приписать ноутбуку. Для смешанного лота «фильтр + регулятор» ноутбук не нашёл подходящий регулятор и не подтвердил общий бюджет. [Точный поиск без ноутбука](kaspi-exact-sandbox-without-laptop-2026-10-07.json), [после исправления с ноутбуком](kaspi-exact-sandbox-fixed-2026-10-07.json).

Ноутбук не ускоряет внешние LLM/Tavily-запросы и не исправляет плохую поисковую выдачу сам по себе. С 3,7 ГиБ RAM оставлено последовательное чтение карточек. Полная серверная тестовая база прошла: 481 тест; после последнего теста URL отдельно прошли 11 адресных проверок. В GitHub ничего не отправлялось.
