# Поиск поставщиков при ограниченном остатке Tavily — 7 октября 2026

Проверки и изменения выполнены локально. GitHub не использовался.

Поиск перестроен вокруг каждого пункта лота: один технически точный запрос, затем более широкий только если не найдена конкретная карточка товара в Казахстане. Количество заказа исключено из текста поиска. Для широкой попытки по регулятору сохраняются фланцевое соединение и 80 мм, а давление 60,3 МПа остаётся обязательным критерием последующей проверки карточки. Результаты каждой позиции получают отдельную квоту, поэтому выдача фильтров не может занять все места регулятора.

Все поиски выполняются с `search_depth=basic`. Число попыток ограничено конфигурацией `SUPPLIER_SEARCH_MAX_CALLS`; на текущей машине лимит **4 на лот**, включая неудачные запросы. Раньше контрольный смешанный лот делал 8 расширенных запросов. В следе песочницы теперь указаны выполненные запросы, лимит, количество вызовов и позиции, для которых не найдена конкретная карточка. Для бюджета всего лота добавлен отдельный вывод: он остаётся неполным, пока у каждой позиции нет подтверждённой цены и количества; доставка не считается подтверждённой автоматически.

На сохранённой реальной выдаче одного базового запроса по регулятору было 5 результатов; фильтр релевантности оставил 4, но ни один фрагмент не подтвердил все 4 ключевые характеристики. Лучший фрагмент подтвердил 2 из 4. Это повод продолжать поиск или запросить уточнение ТЗ, а не объявлять закупку обеспеченной. [Запись живого запроса](regulator-one-query-2026-10-07.json), [воспроизводимая проверка без API-вызовов](supplier-search-offline-eval-2026-10-07.json), [скрипт](../scripts/evaluate_supplier_search.py).

Бесплатный HTML-поиск DuckDuckGo проверен на трёх формулировках без Tavily: по точному регулятору — 3 результата, по широкому — 10, по фильтру с артикулом — 10. По регулятору первые результаты содержат другую арматуру или не подтверждают 60,3 МПа. По фильтру обнаружена конкретная карточка CarCity: её микроразметка указывает 5 999 ₸ за штуку и наличие, поэтому 10 штук стоят 59 990 ₸ без доставки — выше бюджета смешанного лота 48 000 ₸. HTML-поиск не включён в автоматический путь: результаты нестабильны и должны проходить те же проверки карточки и бюджета. [Результаты](free-search-probe-2026-10-07.json), [скрипт](../scripts/probe_free_search.py). Browser-Use не запускался: для чтения Kaspi уже работает ноутбук, а облачный сервис без баланса недоступен.

Один полный живой прогон с лимитом 4 базовых вызова Tavily занял 106,4 с. Ноутбук прочитал 3 карточки, агент оставил 3 кандидата по фильтру, но не подтвердил регулятор и общий бюджет. Песочница честно показывает `budget_summary.status=incomplete`. В прогоне обнаружилась ещё одна ошибка: URL поисковой страницы OLX мог получить статус полного соответствия. После прогона такие адреса отнесены к каталогам, и тест проверяет, что статус `fits` по ним снижается до `partial`. Повторный полный живой прогон не выполнялся из-за остатка кредитов.
